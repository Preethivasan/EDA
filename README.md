# EDA Weekly Tasks

This repository contains the **weekly tasks and practical exercises** for Exploratory Data Analysis (EDA) using Python.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Tasks

The tasks are organized week-wise:

* Week 1
* Week 2
* Week 3
* Week 4
* And so on...

Each folder contains the respective weekly task, notebook, dataset, and related files.

## Objective

To learn and apply EDA concepts such as:

* Data Understanding
* Data Cleaning
* Data Analysis
* Data Visualization
* Finding Insights
